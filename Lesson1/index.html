Lesson 1 Introduction to HTML

Every website you have ever visited starts with HTML. In this lesson you will meet the language that gives web pages their structure.

What is HTML?

HTML stands for HyperText Markup Language. It is the standard language used to create web pages. HTML describes the structure of a page: what is a heading, what is a paragraph, and where images and links belong.

HTML is written using elements. Most elements have an opening tag such as <p>, some content, and a closing tag such as </p>. Your browser reads these tags and turns them into the page you see on screen.

You do not need any special software to start. A simple text editor and a web browser are enough to write and view your first page.
